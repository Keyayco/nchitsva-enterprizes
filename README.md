# Nchitsva Enterprizes Website

A lightweight, mobile-first business website built with plain HTML5, CSS3 and vanilla JavaScript.

## Run locally

Open `index.html` directly in a browser. No build step, package manager or server is required.

## Deploy to GitHub Pages

Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the repository settings. The site uses only local HTML, CSS, JavaScript and image assets.

## Included files

- `index.html` — semantic page structure and content
- `styles.css` — responsive design system and layout
- `script.js` — mobile menu and scroll reveal behaviour
- `assets/nchitsva-logo.png` — supplied Nchitsva Enterprizes logo
